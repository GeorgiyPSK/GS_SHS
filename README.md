# GS_SHS
SmartHomeServer
------------------------------------------------------------------
Сервер сценариев и визуализации для проектов Умного Дома
------------------------------------------------------------------
------------------------------------------------------------------
Install.bat - установка сервера
start_waitress.bat - запуск
localhost:5000 Admin:165538

- Отображение состояния элементов
- Изменение состояний
- Загрузка планов помещения
- Размещение на планах элементов системы
- Создание сценариев взаимодействия элементов системы
- Два режима – просмотр и редактирование
- поддержка ZigBee2MQTT (пока не тестировал)
- Взаимодействие средствами MQTT и HTTP
- Таймеры
- MQTTтриггеры (запуск сценариев при получении сообщения)
- поддержка ModBus RTU и TCP
- поддержка KNX (IP шлюз)
- поддержка событийных LUA скриптов
- Полноценный API для разработки собственной UI
